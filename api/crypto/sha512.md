# universe_crypto_sha512

## Purpose

SHA-512 (FIPS 180-4): streaming context + one-shot, 64-byte digest. Identical
structure to SHA-256 but with 64-bit words, 128-byte blocks, 80 rounds, and a
128-bit length field. The `alwaysinline` compression leaf keeps `a..h`
register-resident across the unrolled rounds; rotations via `llvm.fshr.i64`,
big-endian loads via `llvm.bswap.i64`, wrapping `i64` adds. Context is
caller-allocated, 200 bytes (align 8).

## Exported API

| Function | Signature (C ABI) | Description | Returns |
| --- | --- | --- | --- |
| `universe_crypto_sha512_init` | `void universe_crypto_sha512_init(void *ctx)` | Initialize a 200-byte context. | — |
| `universe_crypto_sha512_update` | `void universe_crypto_sha512_update(void *ctx, const void *data, int64_t len)` | Feed `len` bytes. | — |
| `universe_crypto_sha512_final` | `void universe_crypto_sha512_final(void *ctx, void *out64)` | Finalize; write 64 bytes. | — |
| `universe_crypto_sha512_hash` | `void universe_crypto_sha512_hash(const void *data, int64_t len, void *out64)` | One-shot. | — |

`ctx` is a caller buffer of **200 bytes**, align 8; `out64` ≥ 64 bytes.

## Use in an LLVM-based environment

```llvm
declare void @universe_crypto_sha512_hash(ptr, i64, ptr)
```

Link: `clang -O3 yourprog.ll build/libuniverse.a -lpthread -lm -o prog`.

## Make a CLI

```c
// sha512cli.c — hash stdin, print hex
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
void    universe_crypto_sha512_hash(const void*, int64_t, void*);
int64_t universe_hex_encode(void*, const void*, int64_t);
int main(void) {
    unsigned char *b = NULL; size_t cap = 0, n = 0; int c;
    while ((c = getchar()) != EOF) { if (n==cap){cap=cap?cap*2:4096;b=realloc(b,cap);} b[n++]=c; }
    unsigned char d[64]; char h[128];
    universe_crypto_sha512_hash(b, (int64_t)n, d);
    universe_hex_encode(h, d, 64);
    fwrite(h, 1, 128, stdout); putchar('\n'); free(b); return 0;
}
```

```
clang -O3 sha512cli.c build/libuniverse.a -lpthread -lm -o sha512cli
printf 'abc' | ./sha512cli
```

## Notes

- Digest 64 bytes; context 200 B / align 8, caller-owned, no malloc. Note the
  200-byte context is the largest of the digest family and is the size HMAC /
  PBKDF2 reserve for their embedded digest state.
- One-shot `_hash` is reentrant; a streaming context is single-threaded.
