# universe_crypto_sha256

## Purpose

SHA-256 (FIPS 180-4): a streaming context plus a one-shot helper, producing a
32-byte digest. The hot leaf is an `internal alwaysinline` compression function
whose 64 rounds are fully unrolled by `-O3` with `a..h` kept in registers;
big-endian word loads use `llvm.bswap.i32`, rotations use `llvm.fshr.i32`, and
all round arithmetic is plain wrapping `i32` add (no `nuw`/`nsw`). The
caller-allocated context is 104 bytes (align 8) — no allocation happens inside.

## Exported API

| Function | Signature (C ABI) | Description | Returns |
| --- | --- | --- | --- |
| `universe_crypto_sha256_init` | `void universe_crypto_sha256_init(void *ctx)` | Initialize a 104-byte context. | — |
| `universe_crypto_sha256_update` | `void universe_crypto_sha256_update(void *ctx, const void *data, int64_t len)` | Feed `len` bytes; call repeatedly. | — |
| `universe_crypto_sha256_final` | `void universe_crypto_sha256_final(void *ctx, void *out32)` | Finalize; write 32 digest bytes. | — |
| `universe_crypto_sha256_hash` | `void universe_crypto_sha256_hash(const void *data, int64_t len, void *out32)` | One-shot init/update/final. | — |

`ctx` must be a caller-provided buffer of **104 bytes**, align 8. `out32` must be
at least 32 bytes. All entry points are `void` (no error codes).

## Use in an LLVM-based environment

`make lib` produces `build/libuniverse.a`. Declare the symbols and call them:

```llvm
declare void @universe_crypto_sha256_hash(ptr, i64, ptr)

define void @digest(ptr %msg, i64 %n, ptr %out32) {
  call void @universe_crypto_sha256_hash(ptr %msg, i64 %n, ptr %out32)
  ret void
}
```

Link:

```
clang -O3 yourprog.ll build/libuniverse.a -lpthread -lm -o prog
```

## Make a CLI

A `sha256sum`-style tool: hash stdin, print lowercase hex (reuses the shipped
`universe_hex_encode`).

```c
// sha256cli.c
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>

void    universe_crypto_sha256_hash(const void*, int64_t, void*);
int64_t universe_hex_encode(void*, const void*, int64_t);

int main(void) {
    unsigned char *buf = NULL; size_t cap = 0, n = 0; int c;
    while ((c = getchar()) != EOF) {
        if (n == cap) { cap = cap ? cap * 2 : 4096; buf = realloc(buf, cap); }
        buf[n++] = (unsigned char)c;
    }
    unsigned char dg[32]; char hex[64];
    universe_crypto_sha256_hash(buf, (int64_t)n, dg);
    universe_hex_encode(hex, dg, 32);
    fwrite(hex, 1, 64, stdout); putchar('\n');
    free(buf);
    return 0;
}
```

```
clang -O3 sha256cli.c build/libuniverse.a -lpthread -lm -o sha256cli
printf 'abc' | ./sha256cli
# ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad
```

## Notes

- **Digest size 32 bytes.** Context is caller-owned, 104 B / align 8; reuse it
  across `update` calls, reinit between messages.
- **Endianness:** targets are little-endian; the module byte-swaps per FIPS.
- **Thread-safety:** stateless one-shot `_hash` is reentrant; each streaming
  context is single-threaded (one thread per context).
- **Allocator:** none — the module never mallocs. You own the context and `out`.
- **HARDENING-TODO:** fast, not constant-time; the context/buffer is not zeroized
  on final. No secret-dependent branches exist in compression, but add
  zeroization + a constant-time review before security-sensitive use.
