# universe_crypto_ed25519

## Purpose

Ed25519 signature scheme (RFC 8032, edwards25519, field `2^255-19`). Field
elements are 4 little-endian `u64` limbs kept canonical after every op, reusing
the audited bignum kernels (`f_mul = bignum_mul` then reduce; `f_inv =
bignum_modinv`). The curve uses extended homogeneous coordinates with ONE
unified complete addition law serving both add and double, so the identity is
never a special case. Correctness-first (mod-per-multiply) and gated on RFC 8032
KATs. Keys are 32-byte seeds and 32-byte public keys; signatures are 64 bytes.

## Exported API

| Function | Signature (C ABI) | Description | Returns |
| --- | --- | --- | --- |
| `universe_crypto_ed25519_public_from_seed` | `void universe_crypto_ed25519_public_from_seed(const void *seed32, void *out_pub32)` | Derive the 32-byte public key from a 32-byte seed. | — |
| `universe_crypto_ed25519_sign` | `void universe_crypto_ed25519_sign(const void *seed32, const void *msg, int64_t msglen, void *sig64)` | Sign `msg`; write the 64-byte signature. | — |
| `universe_crypto_ed25519_verify` | `int32_t universe_crypto_ed25519_verify(const void *pub32, const void *msg, int64_t msglen, const void *sig64)` | Verify a signature. | 0 OK / non-zero bad |

`seed32` / `pub32` are 32 bytes; `sig64` is 64 bytes. The public key is derived
internally on sign (the seed is the private key).

## Use in an LLVM-based environment

```llvm
declare i32 @universe_crypto_ed25519_verify(ptr, ptr, i64, ptr)
```

Link: `clang -O3 yourprog.ll build/libuniverse.a -lpthread -lm -o prog`.

## Make a CLI

```c
// ed25519cli.c — sign stdin with a 32-byte seed file, print the signature as hex
// argv: seed.bin
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
void    universe_crypto_ed25519_sign(const void*, const void*, int64_t, void*);
int64_t universe_hex_encode(void*, const void*, int64_t);
int main(int argc, char **argv) {
    if (argc < 2) { fprintf(stderr, "usage: %s seed.bin < message\n", argv[0]); return 2; }
    unsigned char seed[32];
    FILE *f = fopen(argv[1], "rb"); fread(seed, 1, 32, f); fclose(f);
    unsigned char *m = NULL; size_t cap = 0, n = 0; int c;
    while ((c = getchar()) != EOF) { if (n==cap){cap=cap?cap*2:4096;m=realloc(m,cap);} m[n++]=c; }
    unsigned char sig[64]; char hex[128];
    universe_crypto_ed25519_sign(seed, m, (int64_t)n, sig);
    universe_hex_encode(hex, sig, 64);
    fwrite(hex, 1, 128, stdout); putchar('\n'); free(m); return 0;
}
```

```
clang -O3 ed25519cli.c build/libuniverse.a -lpthread -lm -o ed25519cli
head -c 32 /dev/urandom > seed.bin
printf 'hello' | ./ed25519cli seed.bin
```

## Notes

- Seed and public key are 32 bytes; signature is 64 bytes; all caller-owned.
- Reentrant; only bignum scratch is allocated internally.
